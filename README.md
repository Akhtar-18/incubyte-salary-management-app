# incubyte-salary-management-app
Assessment for Incubyte - Salary management app

## Features

- Employee CRUD
- Salary insights
- Country-wise salary metrics
- Job-title analytics
- 10,000 employee seed support
- TDD-driven development

## Tech Stack

### Backend
- Node.js
- Express
- Prisma
- SQLite
- Vitest

### Frontend
- React
- TypeScript
- Material UI
- React Query

## Development Approach

This project follows:
- Test Driven Development (TDD)
- Incremental commits
- Clean Architecture principles
